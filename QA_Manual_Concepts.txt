- Functional vs. Non-functional Testing
- Testing Levels: Unit, Integration, System, Acceptance

- Smoke vs. Sanity Testing
- Risk-Based Testing
- Black Box vs. White Box Testing
- Alpha vs. Beta Testing
- Exploratory, Compatibility, and Ad-hoc Testing
- Performance Testing
- User Acceptance Testing (UAT)
- Static vs. Dynamic Testing
- Monkey and Gorilla Testing
- QA Terminologies: Jira, RTM (Forward, Backward, Bidirectional)
- User Stories and Acceptance Criteria (Given-When-Then)
- Test Scenario vs. Test Case
- Test Case Design Techniques:
  - Equivalence Partitioning
  - Boundary Value Analysis
  - Decision Tables
  - State Transition Diagrams
  - Orthogonal Arrays
  - Use Case Testing
- Structure-Based Techniques: Statement, Decision, Path, and Condition Coverage
- Experience-Based Techniques: Exploratory Testing and Error Guessing
- Verification vs. Validation
- Project Models: Waterfall, Agile, Scrum (Roles, Ceremonies, Artifacts)
